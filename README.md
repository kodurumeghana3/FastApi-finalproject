

# 🏥 MediCare Clinic API

A FastAPI-based backend to manage **doctors** and **appointments** with features like filtering, sorting, and pagination.

---

## 🚀 Features

### 👨‍⚕️ Doctors
- Get, add, update, delete doctors
- Search, filter, sort, paginate
- View summary

### 📅 Appointments
- Book, confirm, cancel, complete
- View all & active appointments
- Search, sort, paginate
- Get appointments by doctor

---

## 🛠️ Tech Stack
- Python
- FastAPI
- Pydantic
- Uvicorn

---
